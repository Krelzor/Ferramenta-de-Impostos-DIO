# Ferramenta-de-Impostos-DIO
Uma ferramenta simples de cálculo de impostos feita baseada nas aulas da DIO

Agregador de Dados para Declaração de Imposto de Renda no Excel

Descrição do Projeto

Este projeto é uma ferramenta interativa feita no Excel para ajudar a organizar e reunir as informações necessárias para a declaração do Imposto de Renda (IRPF).

A ideia é facilitar a vida do usuário com uma interface simples, menus de navegação, validação automática de dados e links rápidos para agilizar o processo de organização financeira.

Objetivos

Organização: Centralizar rendimentos, despesas, bens e direitos em um só lugar.

Validação de Dados: Evitar erros de digitação e dados inconsistentes usando regras de validação.

Usabilidade: Garantir que qualquer pessoa consiga usar a planilha facilmente, sem precisar de conhecimento avançado em Excel.

Documentação: Registrar o projeto de forma clara e compartilhar via GitHub.

O que a ferramenta faz

Dashboard e Navegação: Menu inicial com botões para alternar facilmente entre as abas.

Validação de Entrada: Campos com regras automáticas (como CPF, datas e valores).

Resumo dos Dados: Consolidação das informações para facilitar na hora de preencher o programa oficial da Receita Federal.

Links Rápidos: Atalhos úteis para sites governamentais e consulta de comprovantes.
